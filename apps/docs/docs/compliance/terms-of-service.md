OffMesh is an offline-capable, peer-to-peer delay-tolerant communication platform. By installing and using the app, you acknowledge:

* **Store-and-Forward Routing:** Messages hop opportunistically between participating smartphones. Intermediate nodes carry opaque binary envelopes without access to underlying message content.
* **Honest Delivery Disclaimer:** Delivery depends on physical node mobility and radio proximity. OffMesh provides honest status indicators (`QUEUED`, `FORWARDED`, `UPLOADED`, `DELIVERED`), but does not guarantee immediate delivery across permanently partitioned or disconnected environments.
* **Emergency Dispatch Notice:** OffMesh is **not** a replacement for primary 911, 112, or local emergency dispatch telephone services.
